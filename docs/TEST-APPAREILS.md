À faire après chaque nouvelle version, **sur un vrai téléphone**.

## iPhone (prioritaire)

### 1. Installation
- [ ] Ouvre l'adresse de Fluxe Suivi dans **Safari** (pas Chrome, pas une autre appli).
- [ ] Touche **Partager** (le carré avec une flèche vers le haut).
- [ ] Choisis **Sur l'écran d'accueil**, puis **Ajouter**.
- [ ] L'icône apparaît sur l'écran d'accueil, **nette** (pas floue, pas pixelisée, pas de bord blanc bizarre).
- [ ] Le nom sous l'icône est **« Fluxe »**.
- [ ] En touchant l'icône, l'app s'ouvre **en plein écran** (pas de barre d'adresse Safari).

### 2. Thème clair
- [ ] Mets l'iPhone en **mode sombre** (Réglages → Luminosité et affichage → Sombre).
- [ ] Rouvre Fluxe : l'app reste **claire** (fond clair, texte foncé). Aucun écran ne passe en sombre.
- [ ] Remets l'iPhone comme tu préfères.

### 3. Séance et données
- [ ] Démarre une séance, ajoute un exercice, remplis 2 séries (charge et répétitions), coche-les.
- [ ] Le **minuteur de repos** se lance après une série cochée ; « +15 s » ajoute du temps ; « Passer » l'arrête.
- [ ] Termine la séance.
- [ ] **Ferme complètement l'app** (balaye vers le haut depuis le bas de l'écran, puis balaye Fluxe vers le haut).
- [ ] Rouvre Fluxe : la séance est bien dans **Historique**, avec les bons chiffres.

### 4. Mode avion
- [ ] Ouvre Fluxe une fois **avec du réseau**, puis ferme-la complètement.
- [ ] Active le **mode avion**.
- [ ] Rouvre Fluxe : l'app s'ouvre normalement, sans message d'erreur.
- [ ] Les titres et les chiffres ont la **bonne police** (étroite et grasse, comme d'habitude), pas une police ordinaire.
- [ ] Les onglets Séance, Historique, Stats et « ? » s'affichent tous.
- [ ] Désactive le mode avion.

### 5. Sauvegarde
- [ ] Va dans **Historique → 🛟 Sauvegarde → Sauvegarder (Fichiers, iCloud, mail…)**.
- [ ] La feuille de partage de l'iPhone s'ouvre : enregistre le fichier dans **Fichiers** (ou envoie-le-toi par mail).
- [ ] Dans le même écran, touche **Importer un fichier** et choisis ce fichier.
- [ ] Le message de fin s'affiche et tes séances sont toujours là (aucune en double, aucune perdue).

### 6. Après la mise à jour
- [ ] Ouvre Fluxe avec du réseau, ferme-la complètement, puis rouvre-la (la nouvelle version arrive parfois à la 2e ouverture).
- [ ] Dans l'onglet **« ? »**, tout en bas, tu lis **« Fluxe v2.4.2 »**.
- [ ] Tes anciennes séances sont toujours là.

## Android (pour plus tard / un ami testeur)

- [ ] Ouvre l'adresse dans **Chrome**.
- [ ] Touche le bandeau **« Installer »** de l'app (ou le menu ⋮ → **Installer l'application**).
- [ ] L'icône est nette, le nom est **« Fluxe »**, l'app s'ouvre en plein écran.
- [ ] L'app reste **claire** même si le téléphone est en thème sombre.
- [ ] Une séance enregistrée est toujours là après fermeture et réouverture.
- [ ] En **mode avion**, l'app s'ouvre avec la bonne police.
- [ ] Dans l'onglet **« ? »**, tu lis **« Fluxe v2.4.2 »**.
